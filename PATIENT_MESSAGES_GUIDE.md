# Patient Messages Feature - User Guide

## How to Access Patient Messages

The **Messages** feature is now fully integrated into the patient app! Here's how to find and use it:

### 📱 Location in Patient App

The Messages section can be accessed from the **Bottom Navigation Bar** which appears on all patient screens:

```
[Home] [Medications] [History] [Messages] [Profile]
                                   ^^^^
```

The Messages icon is the **4th icon** from the left (envelope/message icon) in the bottom navigation.

### 🚀 Where to Find It

You can navigate to Messages from any of these patient screens:

1. **Patient Dashboard** (Home screen)
   - Look at the bottom navigation bar
   - Tap the "Messages" icon (4th from left)

2. **Medications List Screen**
   - Same bottom navigation bar
   - Tap "Messages"

3. **Adherence History Screen**
   - Same bottom navigation bar
   - Tap "Messages"

4. **Profile Screen**
   - Same bottom navigation bar
   - Tap "Messages"

### ✨ Features Available

Once you tap on Messages, you'll see:

#### **Conversation List View**
- List of all your caregivers
- Unread message badges showing new messages
- Last message preview
- Timestamp of last activity

#### **Chat View** (when you select a conversation)
- View all messages in the conversation
- Send new messages to your caregiver
- Real-time updates (messages appear automatically)
- Auto-scroll to latest message
- Back button to return to conversation list

### 🔔 Key Capabilities

✅ **View Messages** - See all messages from your caregivers
✅ **Send Replies** - Respond to caregiver messages
✅ **Real-time Updates** - New messages appear automatically
✅ **Unread Badges** - Know when you have new messages
✅ **Multiple Conversations** - Chat with different caregivers

### 💡 Important Notes

1. **Bottom Navigation is Always Visible** - You can access Messages from any screen in the patient app
2. **Badge Indicators** - Unread messages show a purple badge with the count
3. **Real-time** - No need to refresh, messages update automatically
4. **Two-way Communication** - Full conversation capability with caregivers

## Troubleshooting

**Q: I don't see any conversations**
A: This is normal if no caregiver has initiated contact yet. Conversations appear when a caregiver sends the first message.

**Q: The Messages icon isn't showing**
A: Make sure you're on a patient screen (not family/caregiver screen). The bottom navigation should show 5 icons including Messages.

**Q: Can I initiate a conversation?**
A: Currently, caregivers initiate conversations. Once a conversation exists, you can freely send messages.
